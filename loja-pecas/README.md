# BitStore

E-commerce de peças de computador feito em Angular (tema escuro, inspirado na Pichau).

## Como rodar
```bash
npm install
npx ng serve --open
```
Acesse http://localhost:4200

## Conceitos usados
Componentização, data binding, *ngIf/*ngFor, serviços com injeção de dependência, roteamento com parâmetro (`/produto/:id`) e HttpClient lendo `public/data/produtos.json`.
